# SCSP_Stage_Converter
Unity工程舞台文件批量转换PMX文件


此工具为半成品
需使用blender 4.4.3、MMD tools插件
blender其他版本没测试过


目前所有的“视频屏幕舞台”都能自动识别，批量转换
勾选inactive GameObject、自动还原舞台效果、自动去除黑影、另存MEE效果包
“视频屏幕舞台”的文件夹路径：xxxxxx\AutoStage\MME_Preview
MMD使用：先导入PMX，再导入VMD


普通舞台【仅有部分舞台效果】
勾选inactive GameObject、自动还原舞台效果、自动去除黑影
部分需要取消勾选inactive GameObject
MMD使用：先导入PMX，再导入VMD


SCSP_Unity工程舞台文件下载，可直接使用Labubu制作的SCSP下载器来下载
https://github.com/patchouliwxy/SCSP-Resource-Downloader


允许二次修改、二次配布
